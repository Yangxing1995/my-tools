说明

本工具支持提取、格式化、压缩和表格查看 JSON 数据，也支持从日志行或混杂文本中剔除非 JSON 内容后解析。

格式化：将压缩的 JSON 转换为带缩进的可读格式；如果输入类似 2026-06-03 stderr F {}， 会提取其中的 JSON 部分再格式化。

压缩：移除 JSON 中的所有空白字符，生成最小化的 JSON 字符串。

脱敏：自动识别并遮蔽手机号、邮箱、身份证号（按内容匹配），以及字段名包含 address/地址 等关键字的地址信息，其余内容保持不变。
